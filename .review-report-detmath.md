## What I added

1. **`Cargo.toml`** — `libm = "0.2"` under `[dependencies]` with a comment
   saying why. Already in `Cargo.lock` (0.2.16) transitively, so no new
   download; `Cargo.lock` untouched (`cargo` will add the edge itself).
2. **`src/detmath.rs`** (new, ~600 lines) — declared in `src/main.rs` beside
   `mod math;`.
   - Free `#[inline]` wrappers over `libm` for f32: `sin`, `cos`, `sin_cos`
     (two calls: `sinf` + `cosf`, never the platform's fused `sincos`), `tan`,
     `atan2`, `acos`, `asin`, `atan`, `powf`, `exp`, `ln` (`logf`), `log2`,
     `log10`, `hypot`, `tanh`, `cbrt`.
   - `powi(x: f32, n: i32)` — plain left-to-right repeated multiply, negative
     `n` = reciprocal, documented. `powi64(x: f64, n: i32)` — same loop.
   - `trait DetF32` (all f32 methods, `dsin()`…`dcbrt()`, plus `dpowi(n)` so a
     call site changes by one letter) implemented for `f32`; `trait DetF64`
     with `dpowi(n)` for the one f64 call the simulation makes.
   - Module docs: why it exists (platform maths libraries disagree in the last
     bit → the goldens), what stays on `std` and why (`sqrt`, `abs`,
     `floor`/`ceil`/`round`/`trunc`, `min`/`max`/`clamp`, `+ - * /`, no
     `mul_add`), and that `powi` is replaced too.
   - Tests: every wrapper agrees |self vs std| within 2e-6 over a spread of
     inputs; `sin_cos == (sin, cos)` bit-for-bit plus sin²+cos²; `powi` ==
     longhand multiplication for n = 0,1,2,3,6 and the reciprocal for n = −3,
     f64 too; trait methods reach the same bits as the free functions;
     `#[ignore]`d `print_the_pinned_table` + `the_libm_rounding_is_pinned` with
     8 `sin`/`cos` and 8 `atan2` input→bits rows marked
     `// TODO coordinator: fill from first run`.
3. **`clippy.toml`** — `disallowed-methods` for `f32::{sin, cos, sin_cos, tan,
   atan2, acos, asin, atan, powf, powi, exp, ln, hypot}` (the 13 asked for)
   **plus `log2`, `log10`, `tanh`, `cbrt`** — the four extra are the wrappers
   `detmath` also provides, and no simulation file uses them, so the superset
   is free and closes the same hole.
4. **Render/non-simulation modules silenced** with **no** code change:
   - `src/game/mod.rs`: `#[allow(clippy::disallowed_methods)]` on 29
     `pub mod art_*;` lines (every art module that uses trig; `art_icons`,
     `art_puddle`, `art_droppings` use none and are untouched).
   - `src/render/mod.rs`: same on `framebuffer`, `hazard_outline`, `hud`, `ink`,
     `library`, `menu`, `overlay`, `minimap`, `lighting`, `zoom`.
   - `src/render/lighting.rs`: on `air`, `ambience`, `engine`, `fixtures`,
     `overhead`, `sources`, `specular`.
   - `src/render/library.rs`: on `pub mod scene;`.
   - `src/music/mod.rs`: on `pub mod synth;`.
   - File-level `#![allow(clippy::disallowed_methods)]`: `src/audio.rs`,
     `src/app.rs`, `src/spectate.rs`, `src/profbench.rs`, `src/game/smoke.rs`.
   - `src/game/world.rs`: **function-level** allow on `draw_scene` only, so the
     file's one simulation site stays guarded.
   - `src/detmath.rs`: allow on `mod tests` (the reference values it compares
     against *are* `std`'s).

## Likeliest compile errors

1. **`clippy.toml` path spelling.** `f32::sin` is the usual spelling for a
   primitive's inherent method, but if clippy rejects it, try `std::f32::sin`
   (or `core::f32::sin`). Symptom: `cargo clippy` errors about an unknown
   disallowed path, or the lint never fires. Everything is converted, so if the
   paths are wrong the build still succeeds and only the guard is lost — worth
   proving by adding a temporary `.sin()` in a simulation file.
2. **`libm` free-function names**: `sinf`, `cosf`, `tanf`, `atanf`, `atan2f`,
   `acosf`, `asinf`, `powf`, `expf`, `logf`, `log2f`, `log10f`, `hypotf`,
   `tanhf`, `cbrtf` (libm 0.2.16).
3. **Unused-import warnings** if any file's `DetF32`/`DetF64` import turns out to
   be test-only. I checked each of the 15 import sites for a non-test call —
   all have one — but this is the first thing to look at if `-D warnings` runs.
4. Long lines I did not rustfmt (they are legal Rust, just unformatted):
   `level.rs`, `drake.rs`, `enemy_wave4.rs`, `harness.rs`, `boss/tests.rs`,
   `minimap`-free. `cargo fmt` will rewrap them.
5. `powi`/`powi64` with a negative exponent use a reciprocal; nothing in the
   simulation passes a negative one.
